Privacy

What Id|le keeps, what it sends, and how to turn each thing off. This page describes what the game's code actually does; if the code changes, this page changes with it.

In short: your worlds, your drawer and any AI keys stay in your browser. The site counts a few anonymous things (no cookies, nothing about you or your world), and it can read public web pages for your creatures. Both can be switched off in ⚙ settings.

Kept in your browser, not sent

  • Your worlds: the creatures, words, pictures, buildings, snapshots, the almanac's history and the family trees are stored in this browser (its local storage and IndexedDB). Clearing the site's data in your browser removes them, so save a backup file now and then (the snapshot menu does that).
  • Your drawer: the things you keep are stored in this browser too.
  • The chat and your AI keys: if you connect an AI in the chat, your key is stored in this browser and is sent only to the provider you chose (for example api.anthropic.com, or the address you typed for an OpenAI-compatible or local model). It never goes to id-le.com, and it is never put in a world file or a snapshot. What you type in the chat goes to that provider too, under their terms, and nowhere else.

Page views, counted by the server

When your browser asks id-le.com for a page (the game, the Id|le-pedia or this page), the server adds it to that day's totals. Nothing runs in your browser for this, and nothing is stored about you. What the totals hold:

WhatHow
Page views and visits, per pagea visit is a page view that the same visitor didn't make in the previous 30 minutes (so a reload isn't a new visit); a returning visit that your browser only revalidates still counts as a page view, and the page's one-time technical reload doesn't count at all
Visitors, as an estimatewithout cookies or identifiers: the server takes a one-way hash (SHA-256) of a salt that changes every day, your network address and your browser's User-Agent, and uses it only to set a few bits in a HyperLogLog sketch, a compact counter of distinct values (2,048 one-byte cells). Only the sketch is stored. It can say "about 600 visitors today" (within about ±2–3%), but nothing in it can be traced back to a person, an address or a browser. The hash itself is never written down; to tell a reload from a new visit, the server keeps it in its memory for at most 30 minutes. The day's salt is deleted within 30 hours, so hashes from different days can't be linked, and a visitor on two days counts on each day
Where visits came fromthe name of the site whose link brought you (for example reddit.com), never the full address, plus a campaign tag (utm_source) if the link had one. "Hidden" when your browser says the link was on another site but doesn't say which (reader apps, links that hide it); "direct" when you typed the address or used a bookmark
Phone, tablet or desktop; countryfrom the browser's User-Agent and the country the hosting network reports for the connection, counted once per visit
Bots, link previews and scriptscounted apart, never mixed with people: a request whose User-Agent says it's a bot, crawler, preview, headless browser or script, or that doesn't say which languages it accepts

If your browser sends Global Privacy Control or Do Not Track, your page views are only added to the page-view count: no visitor estimate, no visit, no referring site, device or country. This counting happens on the server for every request, so the ⚙ switch below (which lives in your browser) doesn't reach it; the GPC / DNT setting of your browser does.

Where it goes: to id-le.com itself, which only adds the counts to daily totals (for example "41 visits, 30 on phones"). Single visits are not stored, and neither are addresses. (The address used to be /lab/stats; it still works for older pages, and receives the same counts.) The totals are kept for about a year. Stats are only counted on the public site: never on a copy you run yourself.

The public helper (reading web pages)

Some creatures read real web pages (Crawlers, and travel mode). A web page isn't allowed to fetch other sites by itself, so id-le.com does it for you: it fetches the public page you or your creatures asked for and hands it back to your browser.

  • Only public http/https addresses; private and local network addresses are refused.
  • It identifies itself to the site as the Id|le helper. Page sizes are capped and each visitor is limited to 60 requests a minute (that count lives in memory for a minute and is never stored).
  • What is fetched is not logged. The hosting network may briefly cache a fetched public page (up to about ten minutes) to be quicker the second time.
  • Linking worlds (optional, in 🌐 connect): to link two worlds, the helper keeps what linking needs, which is your world's code and the name you give it, the links you approve, the creatures and souvenirs on their way between linked worlds, and when each world was last open.

Turn it off in ⚙ settings → Public helper: no pages are read for that browser and linking pauses; the features that need it say so.

The data lab (Jeffy classifiers)

In the 🧪 data lab, creatures are real text classifiers from Jeffy, a sister project by the same author. To label a message, the helper sends that message's text (at most 500 characters) and the classifier's name to Jeffy's public server, playground.jeffyclassify.com, and returns the label.

  • Only the text being classified is sent, in batches from many visitors at once, through the endpoint that does not keep the text. Nothing else about you or your world is sent.
  • Requests are limited (20 a minute per visitor, and a cap on how many are in flight) so the shared server stays responsive; when it is busy, creatures simply wait.
  • The request comes from id-le.com's helper, not from your browser, so Jeffy's server does not see your network address; it logs that a batch arrived, as most web servers do.

The data lab only runs when you open it. Turning off the public helper in ⚙ settings also turns this off.

Who's playing right now (the live view)

So the maker can see, live, how many people are playing and where they are in the game, an open tab of the game, the Id|le-pedia or this page says "I'm here" to id-le.com/lab/here about every 20 seconds while it is on screen, and "bye" when it is closed or hidden. It follows the same ⚙ switch as the anonymous stats, and it sends nothing if your browser sends Global Privacy Control or Do Not Track. Each "I'm here" carries only:

  • a random number made when the page loaded, kept only in that tab's memory (never stored; a reload makes a new one), so two tabs count as two players
  • phone, tablet or desktop
  • how you're playing: the storyline (and, only while different beginnings are being tested, which one this browser got: straight into the story, a choice first, or the playground; the epoch and step reached), the playground (from nothing or a ready world) or the plain world
  • which panels are open (music, studio, the Operator, a creature card, ⚙…), at most three
  • how many creatures your world has, as a range (0–12, 13–30, 31–60, 61–150, more)
  • how many seconds ago the page was opened
  • whether this browser had been here before (a yes/no, not an identifier)
  • which page: the game, the Id|le-pedia or this privacy page
  • where the visit came from: the name of the site the link that brought you was on (its hostname only, lowercased, without "www.", at most 60 characters), never the full address, its path or its query; "direct" when there was no link or it came from our own pages
  • the link's campaign tag, if it had one (utm_source or ref, letters, digits and dashes only, at most 24 characters)

The server adds the country Cloudflare guesses from your address; the address itself is not kept. All of it is held in memory only, for about a minute after the last "I'm here", then dropped. It is never written to storage, never added to the daily totals and never linked to anything else. Only the maker can see the live view, with a private key. Never sent: words, messages, names, anything from your world, AI keys.

Bring your own agent (staging only for now)

In 🔮 Oracle → connect an agent you can let an agent of your own (Claude Code, a script, anything that speaks HTTP) watch and act in your world while the tab is open. Nothing happens until you click allow. Then:

  • your tab gets a 6-letter code, good once and for 10 minutes; whoever has the code can pair, so only give it to your own agent
  • while connected, about once a second your tab sends a summary to id-le.com's relay: the weather, whether a rave is on, counts, the families, the nearest 20 creatures' names, families, jobs and moods, the storyline's epoch and the last few world events. Never your world file, your chats, your AI keys or anything from your browser's storage
  • your agent reads that summary and asks for actions (weather, spawn, rename, evolve, rave, look, feed, say); your tab runs them with the Operator's own tools and the answers go back the same way. During Genesis only look and say work
  • the relay holds the session in memory only: the summary, the last 100 events, and a random token for your agent. Nothing is written to storage or logged. It is dropped when you click disconnect (the 🤖 pill), when you close the tab (or it stops answering for 30 seconds), or after 4 hours, whichever comes first
  • agents get at most 30 actions a minute

Your agent itself is yours: what it does with the summary is between you and it.

Tell the scientists and roadmap votes

When you use 🧪 Tell the scientists, these are sent to id-le.com and kept in a private list for 180 days:

  • the kind you picked (an idea, a bug, something you loved, something that felt off) and the words you wrote (at most 600 characters). Email addresses, links and phone numbers are blanked in your browser and again on the server.
  • only the context you left ticked in the form: which page, which place in the game, the version, phone/tablet/desktop, and the last error message the page saw. Never anything from your world, your chats or your AI keys.

It is read by the maker of Id|le to decide what to fix and build. It is not published, and it is not sent to GitHub. If an idea makes it onto the public roadmap, it appears in the maker's own words, never with yours or with any context. To avoid floods, the server allows a few messages a day per visitor; for that it keeps a hash of your network address mixed with a secret that changes every day, for two days, and never the address itself. No account, no cookie.

Roadmap votes: the list itself is public. A vote adds 1 to an item's count. This browser remembers which items you voted for (in its own storage), and the server keeps each visitor to one vote per item per day with the same daily hash, kept two days. Only the counts are kept.

Reviews and the team

When the maker asks for ⭐ a review (for example of the logo animations or the fonts), each swipe and pick you make is sent to id-le.com in small batches:

  • your swipes (✕ nah, ✓ like, ★ love, kept as scores 1, 3 and 5) and your "which one?" picks (which of two items you preferred). They are added to each item's totals (how many, their sum, how many of each score) and to a count of head-to-head wins per pair. Next to the totals the server keeps, for your browser key's hash only, which items and pairs it already sent (so nothing counts twice).
  • your notes, if you wrote any (at most 300 characters each; email addresses, links and phone numbers are blanked). They go to the same private list as 🧪 Tell the scientists, kept 180 days, read by the maker, never published.
  • a browser key: a random key made in your browser, sent only when you send a review, kept hashed, used to stop double reviews and so you could claim your reviews later; clearing site data forgets it. It isn't made from anything about you or your device, and the anonymous stats never use it.

The team (the Humans in the Loop): when you press I'm in, your browser key is sent once and id-le.com keeps its hash, the time you joined and how many review batches you sent (that count is how the 14-day, 3-review cliff can be checked later), plus the team's size. Your status (vesting, ✓, your level) is worked out and kept in this browser. Nothing else about you is kept, and nothing from your world is sent.

To avoid floods, the server also counts reviews per visitor per day with the same daily hash as votes (kept two days).

Founder gifts

A personal gift link stores, on id-le.com, only the letter the maker wrote for it (with a private label he gave it) and whether the link has been opened, for up to 180 days. Opening it marks it opened; nothing about the reader is stored with it. Whether this browser is a Founder, the letter it opened and the creature it made stay in this browser's own storage, like the rest of your world.

Hosting

id-le.com is a static site served by Cloudflare. Like any website, the hosting network handles your connection to deliver the pages; Id|le has not turned on any request logging of its own.

Questions

Write to privacy@id-le.com, or open an issue on the project's repository. Id|le is open source, so everything this page describes can be checked in its code.
